Getting started

  1. Install the computer app. Download the Windows agent and run the installer. Allow it through the Windows Firewall when asked — your phone needs that permission to reach it.
  2. Connect to the same Wi-Fi. Put your phone and computer on the same Wi-Fi network.
  3. Tap your computer. Open the phone app, tap your computer in the Nearby Devices list, check the confirm code matches on both screens, and confirm on the computer. You only do this once.

After that, the app reconnects automatically whenever you reopen it on the same network.
