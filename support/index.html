Support

Before contacting support, check Troubleshooting — most connection problems are the same-Wi-Fi or firewall cases covered there.

If you still need help, the Windows agent keeps a local log file (event types and timestamps only — it never contains what you typed or clicked). Attaching that log to your support message helps us find the problem. A support contact address will be published here before the closed beta opens.

Mousely Clone is a working title — the final product name will be announced before public launch. No cookies. No analytics. No accounts.
